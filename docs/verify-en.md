# Verification coverage catalogue

What each assertion group of `npm run verify` (equivalent alias: `npm test`) pins. This file doubles as the repo's regression contract: when behavior changes, change this first, then the implementation. It is the detailed page linked from the README's Verification section (Chinese mirror: [verify.md](verify.md)); the file map lives at [file-map-en.md](file-map-en.md).

CI (`.github/workflows/ci.yml`) runs `npm run lint` + `npm run verify` on Node 18 and 22 for every push and PR.
