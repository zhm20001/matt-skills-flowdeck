# ask-matt

**ask-matt is the router for the whole skill pack**: it organizes every skill into one flow map — a mainline from idea to ship, a few on-ramps feeding into it, a set of standalone skills, and two foundational vocabularies — then recommends an entry point for where you actually are.

## Which routes it knows

- **Mainline**: grill-with-docs → (detour through prototype when needed, with handoff bridging both ways) → to-spec → to-tickets → implement (runs tdd + code-review internally).

- **On-ramps**: inbound issues piling up → triage; something broken → diagnosing-bugs; work too big for one session → wayfinder.

- **Standalone skills**: grill-me, resolving-merge-conflicts, prototype, research, to-questionnaire, wizard, wait-what, teach, writing-for-agents.

- **Foundational vocabularies**: domain-modeling (domain language) and codebase-design (deep-module vocabulary).

- **Stage boundaries**: how to choose among the five options — Continue / clear / handoff / subagent / compact.

## When to use

- You are not sure which skill to enter through.

- You want to know which flow the work in front of you belongs to.

- You want an explicit decision at a stage boundary (continue, clear, hand off, or compact).
