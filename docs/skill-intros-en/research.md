# research

**research delegates the reading legwork to a background agent**: it investigates the question you give it against **primary sources** (official docs, source code, specifications, first-party APIs — not someone else's retelling), traces every conclusion back to the source that owns it, then writes it up as a cited Markdown note stored where the repo keeps notes of this kind.

The point is **you don't wait**: the agent reads in the background while the main line keeps working. The note it produces is material for the main workflow — take it to grill-with-docs or to-spec; it is an input to the thinking, not a substitute for it.

## When to use

- You need a topic investigated, or documentation or API facts gathered.

- A wayfinder research ticket (this is exactly what it runs internally).
