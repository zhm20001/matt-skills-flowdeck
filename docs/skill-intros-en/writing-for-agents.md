# writing-for-agents

**writing-for-agents is the writing reference for documents meant to be consumed by agents** — skills, AGENTS.md / CLAUDE.md, documents that a context pointer points at: different packaging, the same craft. Core concepts: the **context pointer** (a standing one-line reference whose wording decides when, and how reliably, an agent reaches for the material); the **two loads** (standing material burns context, a catalogue of documents burns human cognition — the human is the index); the **information hierarchy** (steps in a file → reference in a file → reference disclosed behind a pointer) and **progressive disclosure**; every step needs a **completion criterion** (clear enough to stop premature jumping ahead, forceful enough to compel real depth); the **leading word** (anchoring a whole swathe of behaviour on a compact concept already present in the model's pretraining, one word standing in for a paragraph of definition); **positive phrasing** (prohibitions drag the forbidden behaviour into context — the more you ban, the more it lives); **pruning** (one source of truth, do not restate the environment, check relevance sentence by sentence, clear out the sediment).

When you are writing a skill, SKILL-MECHANICS.md separately covers frontmatter and the choice of invocation style.

## When to use

- Creating or modifying a skill.

- Editing AGENTS.md / CLAUDE.md.

- Writing any document an agent is supposed to read.
