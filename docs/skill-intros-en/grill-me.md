# grill-me

**grill-me is the stateless entry point to the grilling interview**: one instruction — "run a /grilling session". Unlike grill-with-docs it does not carry domain-modeling along: it creates no CONTEXT.md, writes no ADR, and leaves no trace on disk.

The setting it is made for is exactly "no working directory": sharpening a plan, a design, a piece of writing — when there is no repo underneath to leave paper trails in. With a repo at hand, go straight to grill-with-docs: the same interview, documents thrown in, strictly better.

## When to use

- You have no working directory and want to question an idea through to the end.
