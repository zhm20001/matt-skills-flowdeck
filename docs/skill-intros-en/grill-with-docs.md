# grill-with-docs

**grill-with-docs = grilling (the interview) + domain-modeling (the docs)**: like grilling, it questions the design tree dry round by round — every round asks all the frontier questions, each with a recommended answer, facts the agent looks up itself, decisions stay with you — and at the moment a term or a decision settles it writes it into the CONTEXT.md glossary and the docs/adr/ decision records.

**Prefer it whenever you have a working directory**: the same interview, but it leaves a paper trail the next session can keep using. With no repo in hand, use the stateless grill-me.

## When to use

- Sharpening an idea, a plan, or a design before starting work in a repo.

- Wanting the interview's output to settle straight into project docs.
