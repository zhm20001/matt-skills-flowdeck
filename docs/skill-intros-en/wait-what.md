# wait-what

**wait-what is a correction you can call mid-conversation** with one sentence: "wait, I lost you — re-pitch it: add some context, use ASD-STE100 Simplified Technical English, use the ubiquitous language from CONTEXT.md." The agent then lands what it just said again in a different telling — supplying the background you were missing, stripping the jargon, aligning to the project's language.

It is the **after-the-fact remedy**, and you can cut in with it while any skill is running; the **before-the-fact remedy** is grill-with-docs — settling the shared language before work starts, so the jargon never surfaces at all.

## When to use

- The agent's last message did not land and you need to hear it pitched another way.
