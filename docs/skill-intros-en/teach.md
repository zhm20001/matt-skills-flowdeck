# teach

**teach turns the current directory into a stateful teaching workbench** that teaches you a topic across sessions. The files are the classroom: MISSION.md records **why** you are learning (the anchor for all teaching); RESOURCES.md collects high-trust resources; learning-records/ notes what you have already learned (used to compute your zone of proximal development); lessons/ is the main output — one self-contained, carefully typeset HTML file per lesson, short enough not to load working memory, each delivering a real small win; reference/ holds print-friendly cheat sheets and glossaries; assets/ holds reusable components (a shared stylesheet first, so the lessons read as one course rather than a pile of one-off pages).

Three strands of pedagogy: **knowledge** comes from high-trust resources (citations throughout, never trusting parametric memory); **skills** are drilled through interaction feedback loops — retrieval practice, spacing and interleaving manufacture desirable difficulties, and fluency (retrievable right now) is distinguished from storage strength (what survives long term), the latter being the goal; **wisdom** is finally handed to a community — it finds high-reputation forums / communities / in-person courses for you. A changed mission is normal; it checks with you before editing MISSION.md.

## When to use

- You want to learn a new concept / skill systematically instead of asking once and moving on.
