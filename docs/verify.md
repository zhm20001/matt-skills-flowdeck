`npm run verify`（等价别名 `npm test`）的每一组断言各自钉的是什么。这份清单同时是本仓库的回归契约：改动行为时先改这里再改实现。本文是 README「验证」一节引用的详细版（英文镜像：[verify-en.md](verify-en.md)）；文件清单见 [file-map.md](file-map.md)。

CI（`.github/workflows/ci.yml`）在每次 push / PR 时于 Node 18 与 22 两个版本跑 `npm run lint` + `npm run verify`。
