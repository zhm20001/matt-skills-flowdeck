# writing-fragments

> ⚠️ 开发中：此技能尚未定稿，行为可能变化。

**writing-fragments 是写作流程「探索（explore）」期**：扩大「能写什么」的空间，**刻意不立结构**——定结构是利用期（writing-beats / writing-shape）的事。形式是一场拷问式访谈，聊出的**片段**随手追加进一个 markdown 文件：锐句、带一行论据的主张、小插叙 / 代码 / 类比、半截念头、引语、按感觉抱团的一组观察、以及最值钱的 **leading word**——一个能扛起整篇文章的紧凑命名（如「曳光弹」「战争迷雾」），命名对了，结构与标题都会跟着它长。

文件格式：顶部一个工作标题 + `---` 分隔的片段流，无小节、无标签、无顺序。**写前必重读**（你可能改过）、只追加不覆盖；「删掉最后一条」「这条磨尖点」都是一等指令。

## 什么时候用

- 有东西想写但还没想清楚——先攒料，别急着搭架子。
