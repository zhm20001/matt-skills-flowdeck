# teach

**teach 把当前目录变成一间有状态的教学工作台**，跨会话教你一个主题。文件即教室：MISSION.md 记你**为什么**学（一切教学的锚）；RESOURCES.md 收高信任资源；learning-records/ 记已学内容（算「最近发展区」用）；lessons/ 是主产出——每个 lesson 一个自包含、排版讲究、短到不压工作记忆的 HTML，给一个实打实的小胜；reference/ 是打印友好的速查卡与词汇表；assets/ 是可复用组件（先有共享样式表，课程才像一个课程而不是一堆一次性页面）。

教学法三条：**知识**从高信任资源来（引注满篇、不信参数记忆）；**技能**靠交互反馈回路练——检索练习、间隔、交错制造「合意困难」，区分流利度（当下想得起）与存储强度（长期留得住），后者才是目标；**智慧**最终交给社群——替你找高信誉的论坛 / 社群 / 线下课。使命变了正常，改 MISSION.md 前先跟你确认。

## 什么时候用

- 想系统学一个新概念 / 新技能，而不是问一次就走。
