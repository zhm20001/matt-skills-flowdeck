# research

**research 把阅读跑腿委托给一个后台代理**：它对**一手来源**（官方文档、源码、规范、一方 API——不是别人的转述）调查你给的问题，每条结论追到拥有它的来源，然后写成一个带引用的 Markdown 笔记，存进仓库放这类笔记的地方。

关键在于**你不用等**：代理在后台读，主线继续干活。产出的笔记是喂给主流程的素材——拿去 grill-with-docs 或 to-spec，它是思考的输入，不是替代。

## 什么时候用

- 要把一个课题查清楚、文档或 API 事实要收集；

- wayfinder 的 research 票（内部就是它）。



## 原文描述



> Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.
