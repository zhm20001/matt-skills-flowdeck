# to-questionnaire

**to-questionnaire 处理「卡你的东西不在你脑子里、在别人脑子里」的决策**：把它变成一份 Markdown 问卷，交给对方异步填，或开会一起过。核心纪律是**拷问「寄」而不是拷问「题」**——只问你永远答得上来的事：寄给谁（角色、专长、与你的关系，定语气与上下文量）、要回什么（你独力定不了的具体决策与事实）；问卷里的问题再瞄准这两者的**缺口**。

产出 `to-questionnaire-<slug>.md`：发现式问卷结构——目的、上下文一段、作答方式（截止与工作量，强调「部分答案」和「不知道」都有用）、按主题分节、**最重要的问题排最前**（异步可能只有一轮机会）、每题一意、附答案空位、确有误读风险才加「为什么问这个」、收尾留万能补遗。答回来的材料喂给 grill-with-docs 或 to-spec。

## 什么时候用

- 决策需要某个领域专家 / 干系人的输入才能继续；

- 与 grill-me 相反方向：它访谈你，这份问卷访谈别人。



## 原文描述



> Turn a decision you can't fully answer into a questionnaire for someone else to fill in.
