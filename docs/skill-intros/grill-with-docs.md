# grill-with-docs

**grill-with-docs = grilling（拷问访谈）+ domain-modeling（文档沉淀）**：像 grilling 一样按轮次把设计树问穿——每轮问全「前沿」问题、每题附推荐答案、事实代理自己查、决策留给你——同时在术语与决策敲定的当口把它们写进 CONTEXT.md 词汇表和 docs/adr/ 决策记录。

**有工作目录时优先用它**：同样的访谈，它留纸面痕迹，下次会话还能接着用。没有仓库在手就用无状态的 grill-me。

## 什么时候用

- 在仓库里开工前，把一个想法 / 方案 / 设计磨利；

- 想让访谈的产出直接沉淀为项目文档。
