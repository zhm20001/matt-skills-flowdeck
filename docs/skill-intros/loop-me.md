# loop-me

> ⚠️ 开发中：此技能尚未定稿，行为可能变化。

**loop-me 是一场有状态的 grilling 会话，唯一产出是工作流（workflow）规格**。它带着「**循环镜头**」审视你的世界：**循环**是生活里反复出现的模式（职业、一周、一个早晨、一件重复的事），可预测才值得**委派**；**工作流**是循环的规格，落在 `workflows/*.md`。词汇表：**触发器**（事件优于定时）、**检查点**（人工核验点，可以没有）、**推右**（检查点能推多晚推多晚——人只被问一次、问在一切就绪时）、**简报**（检查点递给你的是决策就绪的摘要，不是原始产出）。

完成判据狠：**实现者代理看完规格不问一个问题才算完**——还有问题就接着拷。工作区另有 NOTES.md 记你的工具、渠道与你自己的叫法，模糊词当场磨成规范词。

## 什么时候用

- 想把自己的某个重复流程设计成可委派的工作流。

> Grill me about specs for the workflows I want to build, within this workspace.
