# grill-me

**grill-me 就是 grilling 访谈的无状态入口**：一行指令——「跑一轮 /grilling 会话」。它不像 grill-with-docs 那样带着 domain-modeling，不建 CONTEXT.md、不写 ADR、不留任何本地痕迹。

适用场景正是「没有工作目录」：磨一个计划、一个设计、一篇文字——底下没有仓库可留纸面痕迹的时候。有仓库在手，请直接用 grill-with-docs：同样的访谈还多送文档，严格更优。

## 什么时候用

- 手头没有工作目录，想把一个想法问透。
