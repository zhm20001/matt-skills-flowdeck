# wait-what

**wait-what 是对话中的即时纠偏**：一句话指令——「等等，我没听懂你到哪儿了。重新讲一遍：补一点上下文，用 ASD-STE100 简明技术英语，用 CONTEXT.md 里的统一词汇。」Agent 于是把刚说的话换一种讲法再落地一遍——带上你缺的背景、拆掉黑话、对齐项目语言。

它是**事后解药**，在任何技能进行中都能插一嘴；**事前解药**是 grill-with-docs——开工前把共享语言谈拢，行话压根不会冒出来。

## 什么时候用

- Agent 刚说的那条消息没落地，需要换个讲法再听一遍。



## 原文描述



> Stop. That last message did not land — re-pitch it.
