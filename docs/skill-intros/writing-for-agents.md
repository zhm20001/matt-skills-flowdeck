# writing-for-agents

**writing-for-agents 是「写给 Agent 消费的文档」的写作参考**——技能、AGENTS.md / CLAUDE.md、被上下文指针指向的文档，包装不同、写法相通。核心概念：**上下文指针**（一句常驻的引用，措辞决定 Agent 何时、多可靠地伸手拿材料）；**两种负载**（常驻材料烧上下文，文档清单烧人的认知——人是索引）；**信息层级**（文件内步骤 → 文件内参考 → 披露到指针后面的参考）与**渐进披露**；每步要有**完成判据**（清晰防抢跑、力度逼出深挖）；**leading word**（用模型预训练里已有的紧凑概念锚定一片行为，一个词省一段定义）；**正向措辞**（禁令把禁止的行为拽进上下文，越禁越活）；**修剪**（单一真相、别复述环境、逐句查相关性、清沉积层）。

写技能时另有 SKILL-MECHANICS.md 讲 frontmatter 与调用方式的选择。

## 什么时候用

- 创建或修改技能；

- 改 AGENTS.md / CLAUDE.md；

- 写任何给 Agent 读的文档。



## 原文描述



> Writing documents for agents. Use when creating or editing skills, or modifying AGENTS.md or CLAUDE.md.
