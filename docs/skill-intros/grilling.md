# grilling

**grilling 是被 grill-me、grill-with-docs、triage、wayfinder、improve-codebase-architecture 反复调用的访谈原语**。方法：把讨论映射成一棵**设计树**——每个决策挂着依赖于它的子决策；按**轮次**推进，每轮把**前沿**（前提已齐、现在就能问的决策）一口气问全，逐题编号并附推荐答案，然后等你回答；你的回答重塑树，前沿外扩，再开下一轮。**查事实是代理的活**（自己派子代理查环境，别拿问题烦用户），**做决策是用户的活**。前沿清空——设计树每个分支都走过、没有默而未宣的假设——会话才算完；用户确认达成共识之前不动手。

## 什么时候用

- 想给一个计划 / 决策 / 想法做压力测试；

- 说了任何「grill」类触发词；

- 想要一场不带任何包装的访谈本身。



## 原文描述



> Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
